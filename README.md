ИИ-АССИСТЕНТ-КОНСУЛЬТАНТ И ПОМОЩНИК ДЛЯ ИНТЕРНЕТ-МАГАЗИНА EKT.KZ

ОПИСАНИЕ ПРОЕКТА

Данный проект представляет собой интеллектуального ассистента для интернет-
магазина электротехнической продукции ekt.kz. Интеллектуальный чат-виджет
встраивается на сайт и помогает клиентам быстро находить товары, изучать
технические характеристики, получать сертификаты, находить аналоги отсутствующих
позиций и уточнять условия покупки. Добавление товаров в корзину осуществляется
строго с явного подтверждения пользователя.

Ключевая ценность:

Сокращение времени принятия решения о покупке.

Снижение оттока клиентов на этапе консультации.

Разгрузка менеджеров отдела продаж от однотипных рутинных запросов.

АРХИТЕКТУРА РЕШЕНИЯ

Система состоит из следующих ключевых компонентов:

Frontend (Чат-виджет):

Встраиваемый адаптивный виджет (Desktop/Mobile).

Поддержка загрузки файлов/изображений (PDF, Word, Excel, JPEG).

Интерактивный UI с отображением карточек товаров и ссылок на корзину.

Backend API & Logic Hub:

FastAPI / Node.js сервис управления сессиями и диалогами.

Модуль валидации корзины и проверки остатков товаров на складах.

Модуль интеграции с OCR / обработкой документов для разбора спецификаций.

AI / RAG Core (LLM Engine):

Vector DB (ChromaDB / Qdrant) для семантического поиска по каталогу.

Hybrid Search (BM25 + Dense Embeddings) для точного поиска по артикулам и наименованиям.

RAG Pipeline: контекстная подгрузка характеристик, сертификатов и условий.

Algorithmic Recommender: подбор и обоснование аналогов при отсутствии позиции.

Data Store:

Синтетическая/анонимизированная база данных каталога ekt.kz (PostgreSQL/SQLite).

СТРУКТУРА ДАННЫХ КАТАЛОГА

База данных/выгрузка каталога содержит следующие ключевые поля:

sku (string): Уникальный артикул товара.

title (string): Полное наименование.

category (string): Категория и подкатегория товара.

specifications (json/text): Ключевые технические характеристики.

certificate_url (string/null): Ссылка на файл сертификата соответствия.

price (numeric): Актуальная стоимость.

stock_balance (integer): Остаток на складе.

status (string): Статус наличия ("IN_STOCK", "OUT_OF_STOCK").

cross_references (array): Список рекомендованных аналогов/замен.

ТРЕБОВАНИЯ И КРИТЕРИИ MUST-HAVE

Поиск и сертификаты: Возврат точных тех. характеристик, актуального наличия
и ссылок на сертификаты по артикулу или названию.

Поиск аналогов: При нулевом остатке система автоматически предлагает 1+
релевантных аналогов с текстовым обоснованием подбора.

Условия покупки: Ответы на вопросы по оплате, доставке и минимальной партии.

Безопасность корзины: Добавление товара в корзину осуществляется ТОЛЬКО
после явного подтверждения клиента (например, "Да, добавь"). Количество
автоматически валидируется с учетом реальных остатков.

Прямая ссылка: Выдача валидной прямой ссылки на корзину после ее обновления.

ИНСТРУКЦИЯ ПО ЗАПУСКУ ПРОТОТИПА

Предварительные требования:

Docker и Docker Compose

Node.js 18+ / Python 3.10+ (для локальной разработки)

Шаг 1: Клонирование репозитория
git clone https://github.com/your-org/ekt-ai-assistant.git
cd ekt-ai-assistant

Шаг 2: Настройка переменных окружения
Создайте файл .env в корневой директории по образцу .env.example:

PORT=8080
DATABASE_URL=postgresql://user:password@localhost:5432/ekt_catalog
OPENAI_API_KEY=your_openai_api_key_here
VECTOR_DB_URL=http://localhost:6333

Шаг 3: Запуск через Docker Compose
docker-compose up --build -d

Шаг 4: Загрузка тестового каталога
python scripts/seed_data.py --file=data/sample_catalog.json

Шаг 5: Проверка работы

Backend API: http://localhost:8080/health

Демо-страница с виджетом: http://localhost:8080/demo
